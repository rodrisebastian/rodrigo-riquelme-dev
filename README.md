# Portfolio — Rodrigo Riquelme

React + TypeScript + Vite. Sin backend. Todo el contenido vive en `src/content.ts`.

```bash
npm install
npm run dev        # desarrollo
npm run build      # typecheck + build en dist/
```

Deploy: Cloudflare Pages (build `npm run build`, salida `dist`). Pendiente: poner `public/cv.pdf` (versión sin teléfono).
